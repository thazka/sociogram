# Code of Conduct

We want sociogram to be a friendly place to learn and to build things.

## Expected behavior

- Be respectful and assume good intent. Disagree with ideas, not with people.
- Give feedback that is specific and kind, and accept it the same way.
- Welcome newcomers. Explain instead of dismissing.
- Keep discussions on topic and technical.

## Unacceptable behavior

- Harassment, insults, discrimination or personal attacks of any kind.
- Publishing other people's private information.
- Sustained disruption of discussions, spam, or deliberately misleading contributions.

## Enforcement

Maintainers may edit or remove comments, issues and pull requests, and may restrict participation, when behavior breaks these rules.

To report a problem, use GitHub's "Report content" option on the comment or issue, or open a private security advisory on this repository if you prefer not to post publicly. Reports are handled confidentially by the maintainers.

This code of conduct applies in all project spaces, including issues, pull requests and discussions.
